# 物归 · 武汉大学失物招领智能匹配系统（在线演示）

一句话：**丢东西的人写「黑耳机」，捡到的人写「AirPods」——纯文字搜不到。物归把两边都解析成同一套结构化描述，用多路向量做跨模态匹配，匹配上主动推送，认领前还要答对只有真主人知道的细节题。**

## 🌐 在线体验

**https://yzj-handsome.github.io/wugui/**

手机、电脑打开即用，不需要安装任何东西。

- **找物品**：试试 `周二下午在图书馆三楼丢了一副黑色蓝牙耳机，充电盒一起丢的，盒子背面有贴纸`
- **发布信息**：结构化填写（类别 / 材质 / 颜色 / 显著特征 / 特殊标记 / 补充说明 + 照片），
  时间地点可选；「我丢了」「我捡到了」同一套表单
- **注册 / 登录**：注册要手机号、真实姓名、学号和密码；登录只输手机号或学号 + 密码
- **办事大厅**：查看我的遗失发布与捡到发布

> 本仓库是**静态演示版**：把真实系统跑出来的数据固化成示例，任何静态托管都能跑，永远可访问。
> 完整版（真实解析、匹配、发布入库、推送投递、认领验证）是本机运行的 FastAPI + 小模型系统。

## 亮点

| 亮点 | 说明 |
| --- | --- |
| 结构化发布 | 类别 / 材质 / 颜色 / 显著特征 / 特殊标记 / 补充说明 + 照片，全部选填，填得越多匹配越准 |
| AI 补全 | 写完补充说明或传照片，可以让 AI 把空着的字段补上（不覆盖你写过的） |
| 五路召回 | 中文语义向量 + 词权重 + 图像向量（图像字幕桥接）+ 时空过滤 + 结构化规则，RRF 融合后 10 项特征打分并概率校准 |
| 可解释分档 | ≥0.80 高度相似（立即推送）/ ≥0.50 需要你确认（每日摘要）/ <0.50 只在搜索里出现；每条给出「相似点」 |
| 认领验证 | 隐藏细节题来自拾主填写的「特殊标记」与照片里不公开的细节，答对才交接；隐藏特征 AES-GCM 加密存储 |
| 隐私分级 | 拾主必须留联系方式，但默认谁也看不到；匹配发生后才按关系逐级放行 |
| 账号体系 | 手机号 / 学号 + 密码登录（PBKDF2 摘要）；学号只存 HMAC 摘要，不保存明文 |
| 办事大厅 | 一屏看全部：我的遗失物品发布、我的捡到物品发布，以及每条的状态 |

## 技术栈

- 模型（全部成品小模型，纯 CPU）：`BAAI/bge-small-zh-v1.5`、`CLIP ViT-B/32`、`RapidOCR`，合计约 250MB
- 后端：FastAPI + SQLAlchemy + SQLite（可切 PostgreSQL + Qdrant）
- 前端：零构建 SPA（原生 ES Module + 自写设计系统，无 npm/打包器）
- 评测：`Recall@10 1.000 / nDCG@10 0.987 / MRR 0.983 / ECE 0.024`（84 条查询、12 对真值的自建评测集）
