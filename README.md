## 亮点

| 亮点 | 说明 |
| --- | --- |
| AI 理解 | 一句话/一张照片 → 类别/颜色/品牌/地点/时间/细节六类字段；不确定的字段会明确标「AI 不确定」 |
| 五路召回 | 中文语义向量 + 词权重 + 图像向量（含图像字幕桥接）+ 时空过滤 + 结构化规则，RRF 融合后 10 项特征打分并做概率校准 |
| 可解释分档 | ≥0.80 高度相似（立即推送）/ ≥0.50 需要你确认（每日摘要）/ <0.50 只在搜索里出现；每条给出「相似点」 |
| 认领验证 | 隐藏细节题（来自拾主照片里不公开的信息），答对才交接；隐藏特征 AES-GCM 加密存储 |
| 隐私分级 | 拾主必须留联系方式，但默认谁也看不到；匹配发生后才按关系逐级放行 |
| 地点与时间 | 武汉大学 126 个真实地点、600 个别名，学部 → 区域 → 楼宇三级可选；时间支持自定起止 |
| 数据看板 | 先结论、再证据、后细节；指标直接来自业务表，不另设埋点 |

## 技术栈

- 模型（全部成品小模型，纯 CPU）：`BAAI/bge-small-zh-v1.5`、`CLIP ViT-B/32`、`RapidOCR`，合计约 250MB 依赖
- 后端：FastAPI + SQLAlchemy + SQLite（可切 PostgreSQL + Qdrant）
- 前端：零构建 SPA（原生 ES Module + 自写设计系统，无 npm/打包器）
- 评测：`Recall@10 1.000 / nDCG@10 0.987 / MRR 0.983 / ECE 0.024`（84 条查询、12 对真值的自建评测集）
